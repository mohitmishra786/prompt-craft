# Contributing to Prompt Craft Pro

Thank you for your interest in contributing to Prompt Craft Pro. We welcome contributions that help improve the quality and utility of generated prompts for AI coding assistants.

## How to Contribute

1. Fork the repository.
2. Create a new branch for your feature or bug fix.
3. Make your changes, ensuring they follow the project's coding standards.
4. Add tests for any new functionality.
5. Submit a pull request with a clear description of the changes.

## Coding Standards

- Use TypeScript for all extension logic.
- Ensure all new features are properly typed.
- Follow the existing project structure and patterns.
- Keep the user experience focused on low-friction prompt generation.

## Reporting Issues

If you find a bug or have a feature request, please open an issue on GitHub. Provide as much detail as possible, including steps to reproduce bugs and examples for feature requests.
