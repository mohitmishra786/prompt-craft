# Security Policy

## Supported Versions

Only the latest version of Prompt Craft Pro is supported for security updates.

## Reporting a Vulnerability

We take the security of our users seriously. If you believe you have found a security vulnerability in Prompt Craft Pro, please report it by following these steps:

1. Do not open a public issue.
2. Email the maintainer directly with a detailed description of the vulnerability.
3. Allow up to 48 hours for a response.

## Security Features

Prompt Craft Pro includes built-in features to protect your data:

- Automatic redaction of common API key patterns (AWS, OpenAI, etc.).
- Support for local LLM execution via Ollama to keep your code on your hardware.
- No storage of code snippets or analyzed data outside of your local VS Code environment.
